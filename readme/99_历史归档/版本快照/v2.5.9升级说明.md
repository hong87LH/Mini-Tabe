# Hong's AI Table Studio v2.5.9 修改日志

## 版本定位

v2.5.9 是基于 v2.5.8「文本大屏编辑」的交互完善版。本次仍然只优化现有表格文本编辑体验，不引入 Workflow，不修改 Provider、Skill Runtime、ComfyUI、OSS、Job、图片/视频生成协议等主链路。

## 本次核心修复

### 1. 修复引用渲染模式 Ctrl/Cmd+C、X、V 失效

原因定位：

- Grid 在 `window` 级监听 `copy / cut / paste`；
- 原逻辑只排除了 `input / textarea`；
- 大屏 Visual 编辑器使用 `contentEditable`；
- 因此 Visual 编辑器内的剪贴板事件被 Grid 当作“表格单元格复制粘贴”拦截并 `preventDefault()`。

修复：

- 新增原生编辑目标判断；
- `input / textarea / select / contentEditable` 均优先使用浏览器原生 Copy/Cut/Paste；
- Grid 的单元格复制粘贴逻辑只在非原生编辑区域生效；
- Delete/Backspace 同样不会误清空表格 Cell。

### 2. 修复 Visual 模式 Ctrl/Cmd+Z / Y 被表格 Undo 抢走

原因定位：

- `App.tsx` 全局 Undo/Redo 也只排除了 `input / textarea`；
- `contentEditable` 没有被识别为文本编辑环境。

修复：

- App 全局 Undo/Redo 增加 `contentEditable` 判断；
- Visual 大屏内 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl/Cmd+Y 使用浏览器原生文本编辑历史；
- 离开编辑器后仍恢复原来的项目级 Undo/Redo。

## 大屏文本编辑体验升级

### 3. 删除“完成”确认按钮

- 大屏编辑不再要求额外点击“完成”；
- 关闭按钮、点击遮罩关闭、Esc 关闭都会保存当前编辑内容；
- 保留 Ctrl/Cmd+S 快速保存；
- 编辑流程更接近普通文本编辑器。

### 4. 智能文本“重新生成”按钮视觉回归原 AI 图片/视频体系

大屏和 Cell 内智能文本二次生成按钮统一采用现有 AI 图片/视频按钮视觉：

- 白底；
- 灰色默认图标；
- 灰色边框；
- Hover 紫色 → Indigo 渐变；
- Hover 白色图标/文字。

不再单独使用一套紫色按钮样式。

### 5. Raw / Visual 中文化

中文界面：

- `Raw` → `纯文本`
- `Visual` → `引用渲染`

英文界面继续保留 Raw / Visual。

## Media 引用渲染升级

### 6. 图片 / 音频 / 视频分别独立编号

编号规则不再使用一个全局序号。

例如同一行：

- Picture 1
- Picture 2
- Audio 1
- Video 1
- Audio 2

三种媒体类型分别维护自己的序号，与 MiniMax 等引用语义保持一致。

### 7. 三种媒体采用独立且一致的视觉色

- 图片 Image：蓝色
- 音频 Audio：紫色
- 视频 Video：紫红 / Pink

这一颜色规则同时作用于：

- 顶部“当前行引用媒体”；
- Visual Prompt 内媒体 Chip；
- `@` 媒体菜单；
- 编号圆点。

避免同一种媒体在不同位置出现不同颜色认知。

### 8. Visual Prompt 媒体 Chip 使用真实缩略图

- Picture / Video Chip 前的小框优先显示真实缩略图；
- Audio 使用统一音乐图形；
- 缩略图尚未异步生成完成时先显示类型占位；
- Thumbnail 完成后直接就地更新 Chip，不重新写整个 contentEditable DOM。

这同时修复了：

> 第一次打开引用渲染时没有图片缩略图，必须 Raw / Visual 来回切换后才出现。

### 9. @ 媒体菜单按类型分组

菜单顺序：

1. 图片
2. 音频
3. 视频

不同类型之间增加分割线，并继续沿用对应类型颜色。

### 10. 引用渲染支持基础结构强调

首版加入可继续扩展的 `highlightLargeVisualSyntax()`：

- `<...>`
- `[...]`
- `【...】`

在 Visual 模式中加粗显示。

注意：这只是显示层 Renderer，保存回 Cell 的仍然是原始纯文本，不引入第二份富文本数据。

## 普通单元格内编辑优化

### 11. 大屏展开按钮视觉简化

- 删除描边；
- 删除投影；
- 保留浅灰底 + 线性 Maximize 图标；
- Hover 仅做轻量灰/蓝反馈。

### 12. 双击进入普通编辑时，展开按钮移到右上角

- 编辑状态：右上角；
- 非编辑状态：仍保持右下快捷入口；
- 编辑状态避开文本区滚动条。

### 13. 减少普通编辑模式文本区域无效避让

Text / AI Text 小编辑框：

- 删除原来的底部大块 `pb-7`；
- 右侧 padding 从 32px 减少到 24px；
- 让文本区域实际可用宽度更大。

### 14. 修复编辑框覆盖下方行时，下方 Cell 展开按钮误显示

编辑某一个 Text/AI Text Cell 时：

- 只有当前编辑 Cell 的展开按钮可见；
- 被扩展 textarea 覆盖到的其它行不再因鼠标经过而出现展开按钮。

实现为 CSS `:has()` 视觉隔离，不增加额外全局状态。
