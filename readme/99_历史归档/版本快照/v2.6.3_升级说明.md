# Hong's AI Table Studio v2.6.3 升级说明

> 基于 v2.6.2 的稳定性修复版本。

## 更新内容

### 1. 修复引用渲染模式换行丢失

修复文本大屏在“引用渲染”模式下编辑时，按 Enter 产生的换行在退出并重新进入后丢失的问题。

现在支持正确保存：
- 普通换行
- 连续空行
- 末尾换行

纯文本编辑模式保持原有逻辑不变。

### 2. OSS 自动复用改为 SHA256 精确校验

为减少相似图片误判导致的 OSS 串图问题，自动复用策略调整为：

```text
SHA256 完全一致
→ 直接复用

SHA256 不一致
→ 重新上传
```

`dHash` 历史字段和索引结构继续保留，用于兼容旧数据，但不再参与自动复用判断。

重点避免以下场景误判：

```text
同一模特
同一构图
仅服装颜色 / 图案 / 局部细节变化
```

即使图片视觉结构非常接近，只要文件内容不同，就会重新上传。

### 3. 修复标签字段 Enter 误选旧标签

修复标签编辑时的模糊匹配问题。

例如已有标签：

```text
A
```

输入：

```text
AI
```

并按 Enter 后，现在会正确创建新标签 `AI`，不会再错误关联到旧标签 `A`。

新规则：

```text
名称完全一致
→ 复用已有标签

名称不完全一致
→ 创建新标签
```

模糊搜索和鼠标选择旧标签的功能继续保留。
