## 修改内容

- 2K、4K 下拉显示恢复为原来的 `2K`、`4K`，不再附加“其他模型”文字；
- 附件选择器允许选择音频文件；
- 附件单元格和附件编辑器为音频显示独立音乐图标，不再尝试按图片加载；
- 点击音频附件可进入统一预览层；
- 预览层使用浏览器原生 `<audio controls>`，支持播放、暂停、拖动进度和音量；
- 支持 MP3、WAV、FLAC、M4A、AAC、OGG、OPUS 以及 `data:audio`。
