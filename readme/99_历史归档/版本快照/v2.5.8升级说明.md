# Hong's AI Table Studio v2.5.8 升级说明

## 版本定位

v2.5.8 基于 v2.5.7，聚焦 **表格模式下文本 / 智能文本的长内容编辑体验**。本次不引入 Flow Canvas / Workflow，不改 Provider、Skill Runtime、图片/视频生成协议和 Job 链路。

核心目标：

```text
小文本：继续双击单元格直接编辑
长文本：一键展开大屏编辑
智能文本：大屏中增加引用媒体的 Visual Prompt 编辑
再次生成：选中单元格即可直接触发
```

---

## 1. 文本单元格新增“大屏编辑”快捷入口

适用字段：

- `text`
- `aiText`

单元格右下角新增浅灰色线性展开按钮。按钮在当前单元格选中时保持可见，其他情况下鼠标悬停显示。

原来的双击编辑行为保持不变。

---

## 2. 大屏文本编辑器

点击展开按钮后，通过 Portal 打开独立大屏编辑层。

支持：

- 常规文本输入、选择、复制、粘贴；
- 浏览器原生 Undo / Redo；
- 多行文本编辑；
- `Ctrl / Cmd + S` 保存；
- `Esc` 保存并退出；
- 字符数显示；
- 点击“完成”写回当前 Cell。

大屏编辑只写回当前记录的当前文本单元格，不修改字段设置。

---

## 3. 智能文本 Visual Prompt

智能文本大屏编辑器额外提供：

```text
Raw | Visual
```

### Raw

直接编辑原始字符串。

### Visual

识别并临时渲染：

```text
<Picture N>
<Image N>
<Video N>
<Audio N>
```

为可视化媒体标签。

Visual 只是显示层，保存时仍序列化回原始文本 Token，不产生第二份 Prompt。

---

## 4. 当前行引用媒体

智能文本大屏顶部会根据当前字段：

```text
aiTextConfig.sourceImageTemplate
```

读取当前行被引用字段中的媒体，并保持字段引用顺序和附件内部顺序。

媒体缩略图：

- 使用现有 `ThumbnailImage` 缩略图链路；
- 显示顺序编号；
- 保留现有裁切 / 扩图图标视觉；
- 点击缩略图继续调用原来的媒体大屏预览，而不是新建预览器。

---

## 5. `@` 插入引用媒体

在智能文本大屏的 Visual 模式下输入：

```text
@
```

会打开当前 Cell 已引入媒体的列表。

选择媒体后，在当前光标位置插入：

```text
<Picture N>
<Video N>
<Audio N>
```

界面显示为媒体标签，后台文本仍保持 Token 格式。

该功能只操作当前文本 Cell，不修改 `sourceImageTemplate`。

---

## 6. 智能文本“再次生成”交互优化

v2.5.7 的问题：

- 已生成文本后，生成按钮不便直接访问；
- 编辑模式右上角按钮会占用文本编辑区域。

v2.5.8 调整为：

- 选中 `aiText` 单元格但未进入编辑状态时，右上角始终可直接“再次生成”；
- 即使 Cell 已经有文本，也可以直接二次生成；
- 小单元格编辑状态不再显示覆盖文本的生成按钮；
- 大屏编辑器 Header 同样提供“重新生成”，触发前先保存当前文本。

原 `onBatchAIGenerate` 生成链路保持不变。

---

## 7. 兼容性原则

本次没有修改：

- AI Text Provider 请求逻辑；
- Skill Registry / Skill Runtime；
- `prompt` / `modelTemplate` / `skillTemplate` 的解析方式；
- `getBase64ImageParts()`；
- Attachment Cell Editor；
- 图片大屏预览；
- AI Image / AI Video；
- ComfyUI；
- OSS；
- Job Center；
- 表格虚拟列表和选择框逻辑。

没有配置参考媒体的智能文本仍可正常使用大屏编辑器，只是顶部媒体区为空。
