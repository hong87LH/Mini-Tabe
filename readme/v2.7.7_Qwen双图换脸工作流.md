# v2.7.7 Qwen 双图换脸工作流

> 本文件保留为版本实现记录。当前安装、模型来源、Action API 与维护规范统一见 `03_ComfyUI/ComfyUI_Qwen_Image_2.1_参数与LoRA.md`；单工作流复现见 `comfyui/workflows/qwen-image-2.1-face/README.md`。

日期：2026-11-06

## 本版新增

- 新增 ComfyUI 本地模型入口 `qwen-image-2.1-face-local`，对应工作流 `qwen-image-2.1-face`。
- 工作流要求两张输入图。图 1 是待编辑的基图，图 2 是面部身份参考。默认图生图比例可随图 1。
- 模型链加载 `bfs_head_v1.1_qwen_2.1.safetensors`，强度为 1。选用 high 画质时以 30 步采样。
- Face 模板自带经实际请求验证的 `head_swap` 结构提示词。表格提示词为空时直接使用模板提示词；有补充要求时按“模板提示词 + 换行 + 用户补充词”提交，不再覆盖模板。
- 已经包含完整模板提示词的旧配置不会重复拼接。普通 Qwen、透明 Qwen、MiniMax H3 仍保持原提示词行为。
- Table Action API 仍为 v0.1，能力阶段仍为 phase4.7，Action Definition 仍为 1.3。

## v2.7.6 表格兼容性

- 不新增必填表字段，不修改 `aiImageConfig`、项目文件夹、记录或附件的数据结构。
- v2.7.6 工程文件可以直接打开；原有 Provider、模型名、字段引用、局部修图和表格内容不需要迁移。
- 旧的本地 Qwen Provider 在运行时只追加可选别名 `qwen-image-2.1-face-local`，不会替换既有模型、端点、Key 或默认选择。
- 保存后的工程仍采用原 JSON 结构；使用新 Face 模型的字段在 v2.7.6 中不会被识别为可执行模型，但不会破坏其他字段数据。

## 源码同步

| 文件 | 用途 |
|---|---|
| `comfyui/workflows/qwen-image-2.1-face/manifest.json` | 工作流注册、双图约束和运行时绑定 |
| `comfyui/workflows/qwen-image-2.1-face/image_api.json` | ComfyUI API 模板、LoRA 和输出节点 |
| `comfyui/workflow_registry.js`、`comfyui/comfyui_client.js` | 读取模板提示词，并按 Manifest 策略追加用户补充词 |
| `comfyui/plugin_catalog.json` | 声明核心节点 `LoraLoaderModelOnly` |
| `src/App.tsx` | 在本地 Qwen 模型列表中提供新别名 |
| `src/components/Grid.tsx` | 双图参考顺序与修图比例处理 |
| `tests/comfyui_protocol.test.mjs` | 双图约束、顺序、LoRA 链路与采样回归测试 |
| `package.json`、`package-lock.json` | 工程与打包版本 |
| `agent_api/action_definitions.js`、`agent_api/table_action_api_v0.1.schema.json` | API 产品版本声明及生成的 Schema |

目标电脑需具备本地 Qwen-Image-2.1 主模型、文本编码器和 VAE。将换脸 LoRA 放入该电脑的 `ComfyUI/models/loras/`。打开对应表格工程后，把对照图字段设为新模型，并按顺序绑定两张参考图。
