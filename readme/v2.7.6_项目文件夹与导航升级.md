# v2.7.6 项目文件夹与导航升级

发布日期：2026-10-14

- 子表支持一层项目文件夹收纳、创建/重命名/解散、展开收起、拖拽排序及跨项目移动。解散项目保留子表，支持撤销。
- 项目内可直接新建子表；子表右键支持移入已有项目、移回根目录、新建项目并移入。拖出目录使用临时插入线，无常驻占位。
- 折叠侧栏按项目切换子表，带返回角标的灰色文件夹按钮返回根目录，滚动条悬停显示。
- 标题显示“项目名 › 子表名”；标题菜单悬停展开项目，超长列表滚动，空间不足时向左展开。新建入口支持中英文。
- JSON保持旧子表数组结构，首表可选projectFolders、子表可选projectId；旧文件兼容，追加导入重建ID与归属。CSV原有功能不变。
- Action API增加project.list/create/rename/delete/reorder与table.move_to_project，支持现有确认、revision、事务与幂等机制。Definition 1.3，共91项Action；协议0.1、phase4.7不变。
- API文档对齐产品版本。Windows复杂调用统一使用UTF-8的--params-file或--stdin，不依赖内联--params的Shell转义容错。

验证：Action API及生成预览回归、类型检查、生产构建；隔离Electron覆盖原生拖拽、目录切换、中英文、标题路径、滚动条显隐、JSON保存/替换/追加与重启恢复。未修改用户真实表格，未提交生成任务。

升级：保存现有工程后重启应用以加载新主进程和preload。建议保留升级前JSON备份；旧版本重新保存文件时可能不保留新增目录信息。无新增依赖或生产脚本。
