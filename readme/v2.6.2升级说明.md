二、FFmpeg 独立目录（v2.6.1 最终标准）
FFmpeg 不放入 scripts，也不写进业务代码目录，而是像 npmnode 一样单独维护。
默认目录统一为：

Hongs_AI_Table_Studio/
├─ npmnode/        （如果你的便携包已有）
├─ ffmpeg/
│  └─ bin/
│     ├─ ffmpeg.exe
│     └─ ffprobe.exe
├─ scripts/
├─ src/
└─ main.js ...

程序优先读取：
- ffmpeg/bin/ffmpeg.exe
- ffmpeg/bin/ffprobe.exe

兼容规则：
- 仍兼容第一版 v2.6.1 的 ffmpeg/ffmpeg.exe、ffmpeg/ffprobe.exe；
- 仍兼容把 ffmpeg 文件夹放在项目上一级目录；
- HONGS_FFMPEG_DIR 可指向 ffmpeg 根目录，也可直接指向 bin；
- 开发机最后可回退系统 PATH。

因此以后分享给同事时，FFmpeg 库可以长期独立保留，日常代码升级包无需重复覆盖它。

三、使用方式
1. 打开音频或视频大屏。
2. 可直接按 A 设置开始点，按 B 设置结束点；播放和暂停状态都支持。
3. 首次只设置 A、当前没有已保存 B：B 自动使用媒体结尾。
4. 只设置 B：A 自动使用媒体开头。
5. 可直接选择 5s / 10s / 15s / 20s 标准 AI 参考片段。
6. 快捷片段可拖动整个选区；自定义 A-B 可拖动边界。
7. 白色播放头可独立拖动，用于精确定位当前帧，不会与整个 A-B 选区拖动冲突。
8. 媒体大屏按 Space 可播放 / 暂停；暂停状态仍可拖播放头并按 A/B 设点。
9. 播放到 B 会自动回到 A，循环预览有效参考范围。
10. 恢复 v2.5.10 图片复制机制：Cell 内复制继续保留 cropData；视频 / 音频按完全相同的内部剪贴板逻辑保留 trimData；单个缩略图 Copy 也支持内部参数复制，外部软件仍只得到媒体路径。
11. 重新打开已经保存 A/B 的媒体时，会恢复原区间并定位到 A；再次按 A 只更新 A，不再把已保存的 B 重置为媒体结尾。
12. A/B 两端手柄在已有片段中始终可见；快捷片段拖任一端后自动转为自定义区间。
13. 清除后恢复完整媒体。
14. 冻结列覆盖普通 Text / AI Text 列时，底层“大屏编辑”悬浮按钮不会再穿透到冻结列最上层。
15. 普通文本临时参考左侧锁按钮支持“本列固定”：激活后退出大屏，再进入同一列其他行仍自动沿用该智能节点；仅保存在 sessionStorage 会话缓存，不写入 Record / Field Config，解除固定或关闭应用窗口后失效。

四、发送 AI Reference
工程文件只保存原始媒体路径与 trimData，不修改源文件。
真正提交 AI Video 时：
原媒体 + trimData
→ media_preprocessor.js
→ 外部 ffmpeg/bin/ffmpeg.exe 生成缓存片段
→ ComfyUI 直接上传，或远程 Provider 先上传 OSS
→ 下游模型只收到指定时间片段。

同一源视频可以在一个单元格中保存多个不同 trimData 实例，互不覆盖。
