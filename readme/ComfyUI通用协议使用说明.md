# ComfyUI 通用协议使用说明（v2.5.0）

> 本文件为初版简要说明。完整且最新的升级、使用、扩展、测试和排错内容，请以同目录下的 `ComfyUI通用协议升级与使用维护手册-v2.5.0.md` 为准。

## 一次性配置

在“API 和模型配置”的视频配置中新增一项：

- 提供商：`ComfyUI Local`
- 接口地址：`http://127.0.0.1:8188`
- API Key：留空
- 模型：`minimax-h3-local`
- 状态：启用

同名模型只能启用一个提供商。如果 Lingwu 配置中也填写了 `minimax-h3-local`，请停用其中一个。

## MiniMax H3 参数

- 分辨率：`0.7MP` 或 `0.9MP`
- 比例：`16:9` 或 `3:4`
- 模式：`fast` 为 Turbo 6 步；`quality` 为原速 20 步
- 时长：支持 3、5、8、10、15 秒；H3较长视频会显著增加时间与显存压力
- 素材：至少一张图片，第二张图片会作为尾帧
- 声音：关闭时，成品不连接模型生成的音轨

## 日常启动顺序

1. 启动 `E:\01_AIGC\ComfyUI_windows_portable_H3` 中的 ComfyUI。
2. 确认浏览器可以打开 `http://127.0.0.1:8188`。
3. 启动本 v2.5.0 工程。
4. 在AI视频列选择 `minimax-h3-local` 并生成。

## 新增其他工作流

在 `comfyui/workflows` 下为每个工作流建立独立目录，并放入：

- `manifest.json`：声明模型别名、支持能力、前台参数到节点输入的映射和输出节点。
- 一个或多个 ComfyUI API 工作流 JSON。

前台、任务队列、状态轮询和下载逻辑无需为每个新工作流重复开发。

## 当前限制

- 当前已正式注册的工作流是 `minimax-h3-i2v`。
- 图片协议骨架已经接通；实际使用某个图片工作流前，仍需为它增加 manifest 与API工作流。
- ComfyUI自身关闭会中断正在采样的任务；只重启本应用时，已经提交的任务可以根据 ComfyUI 队列或历史继续查询。
