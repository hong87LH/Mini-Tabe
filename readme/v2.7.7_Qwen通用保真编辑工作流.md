# v2.7.7 Qwen 通用保真 LoRA Profile

> 本文件保留为版本实现记录。当前安装、模型来源、Action API 与维护规范统一见 `03_ComfyUI/ComfyUI_Qwen_Image_2.1_参数与LoRA.md`。

## 作用

- 默认 Qwen 字段设置新增“保真增强”复选框，启用后写入 `loraProfiles: ["consistency"]`。
- 使用 `qwen-image-2.1-consistency.safetensors`，面向通用画面修改、降低主体与构图偏移。
- 它复用 `qwen-image-2.1` 的默认模板和动态多图路由，不再维护一份重复 Workflow JSON。
- 与 `qwen-image-2.1-face-local` 分开：Face 有固定双图语义和默认提示词，Consistency 只是模型增强层。
- 旧别名 `qwen-image-2.1-consistency-local` 仍由工作流和 Provider 识别，但不出现在新字段的模型候选列表中。
- “保真增强”复选框只控制 Consistency；右侧“功能 LoRA”下拉框是独立入口，专门用于以后登记的工艺、人物或具体编辑功能 LoRA，二者不互相启停。

## 输入约定

- 沿用默认 Qwen 路由的 0–5 张图片能力。
- 已增加 1 张、2 张、5 张图片协议回归；第一张图继续作为原生 latent 和主要基图。
- Consistency 主要用于有参考图的编辑；无图时技术上仍可走默认文生图路径，但没有保真编辑意义。

## 提示词规则

- 沿用默认 Qwen 模板的提示词替换逻辑。
- 表格提示词原样写入 ComfyUI，不追加 Face 默认提示词，也不自动补写结构指令。
- 建议用户在提示词中同时说明“需要修改的内容”和“必须保持不变的内容”。

示例：

```text
把外套改为深蓝色羊毛材质，保持人物身份、姿势、构图、光照、背景和其他服装细节不变。
```

## v2.7.6 兼容性

- 没有修改项目、表格、字段、记录、附件和媒体实例的数据结构。
- v2.7.6 表格可直接在 v2.7.7 打开，无需迁移。
- 新增模型只是本地 Qwen Provider 的可选别名，不改变旧字段的模型选择。
- 使用新模型保存的字段回到 v2.7.6 时无法执行该模型，但不会破坏其他表格数据。

## 后续叠加 LoRA

- Manifest 的 `loraProfiles` 负责登记允许使用的 LoRA 文件和默认强度。
- `aliasLoraProfiles` 可以把模型别名映射为一组默认 Profile。
- 生成参数 `loraProfiles` 支持按顺序注入多个已登记 Profile，运行时自动建立 `LoraLoaderModelOnly` 模型链。
- 不接受未登记文件名，避免 Agent 或表格值任意加载本机 LoRA。

## 使用方式

新字段推荐保留基础模型：

```text
qwen-image-2.1-local
```

然后在字段设置中勾选“保真增强”。Agent/API 等价配置为：

```json
{
  "model": "qwen-image-2.1-local",
  "loraProfiles": ["consistency"]
}
```
