# AI Table Studio v2.6.9：缩略图路径与裁切预览修复

日期：2026-09-06

产品版本：2.6.9

Table Action API：v0.1 / phase4.7（未变更）

## 本次更新

### 1. Windows 本地图片缩略图路径兼容

- 修复表格中使用 `F:/folder/image.png` 一类正斜杠盘符路径时，文件真实存在但 Electron 系统缩略图返回空值、界面显示破损图片的问题。
- 主进程在请求 Windows 系统缩略图前统一将盘符路径规范化为反斜杠格式。
- 不修改表格中已经保存的附件路径，不需要迁移历史数据。
- 保留 v2.6.8 的可视区域懒加载、并发限制、请求去重及 NAS 原图保护；系统缩略图失败时仍不会无条件加载 NAS 大原图。

### 2. 历史裁切实例预览精准复原

- 修复旧 `cropData` 在窗口尺寸、显示分辨率或参考面板布局变化后，重新打开时出现取景范围缩小及位置偏差的问题。
- 原因是旧预览逻辑只恢复像素级 `scale / x / y`，没有根据保存时的 `imgW / imgH / maskW / maskH` 适配当前图片显示尺寸。
- 新逻辑先还原裁切区域在原图中的归一化位置和范围，再依据当前预览尺寸重新计算缩放与位移。
- 使用 `ResizeObserver` 处理预览窗口或参考区域尺寸变化，避免打开后再次改变布局造成漂移。
- 不重写历史 `cropData`；生成、导出和 Media Instance 的持久化结构保持兼容。

## 实际数据核验

以测试时用户选中的附件单元格为例：

- 原图实际尺寸为 `1200×3785`，与历史 `cropData.naturalW / naturalH` 一致。
- 同源图片的 6 个裁切实例均保存了完整的 `scale、x、y、ratio、imgW、imgH、naturalW、naturalH、maskW、maskH`。
- 6 个裁切矩形换算回原图后全部处于有效范围内，说明持久化数据没有损坏。
- 尺寸变化复原测试中的原图坐标偏差低于 `0.01px`。
