# v2.7.7 ComfyUI 工作流维护与 Action 同步

日期：2026-11-07
产品版本：v2.7.7
Action API：v0.1 / phase4.7 / Action Definition 1.3

## 更新内容

1. 四个正式 ComfyUI workflow 均补齐随附维护说明；H3、Qwen 基础、Qwen Face 的模型文件、安装目录、节点依赖、来源和输入语义可独立复现。
2. 四份 Manifest 新增向后兼容的 `modelRequirements`，结构化登记精确文件、目录、来源、加载节点、输入名、模式条件及可选 SHA-256。
3. Consistency 保留为默认 Qwen workflow 的可选 Profile；Face 保持独立双图 workflow，不混用提示词或 Profile。
4. ComfyUI Health 在加载节点公开选项时核对模型文件，新增 `requiredModels` 与 `missingModels`；自定义节点不公开选项时不误报。
5. `generation.get_capabilities` 的 `comfyuiWorkflows` 新增 `modelRequirements`、`loraProfiles`、`aliasLoraProfiles`。
6. `generation.preview` 对智能图片回显实际启用的 `resolvedConfig.loraProfiles`；Profile 未登记或与 workflow 不匹配时返回 `WORKFLOW_LORA_PROFILE_UNSUPPORTED`。
7. `field.configure_ai` 继续使用既有可选 `model` 与 `loraProfiles`，没有修改 v2.7.6/v2.7.7 表格存储结构。
8. 修正 Face 模型在字段设置面板中未命中 Qwen 分辨率规则的问题；现在显示 `0.5K / 1K / 1.5K / 2K`，并保持固定双图语义。
9. `generation.preview` 新增 Manifest 驱动的分辨率校验；Face 与默认 Qwen 共用 0.5–2K 上限，超限返回 `WORKFLOW_RESOLUTION_UNSUPPORTED`。
10. 功能 LoRA 控件新增字段引用入口；引用值按行解析，支持逗号、分号或换行分隔，并继续由 Manifest 白名单校验。
11. ComfyUI 模型设置页新增 Manifest LoRA 清单：区分“字段值 Profile”和“工作流内置 LoRA”，支持一键复制配置值或文件名，不新增第二套注册数据。
12. 注册表按 `bindings.prompt` 自动抽取实际 Workflow 模板默认提示词；Face 的 `head_swap` 等内容可在模型设置页查看和复制，无需在 Manifest 重复抄写。
13. LoRA Profile 新增兼容式 `promptPolicy`：支持触发词、默认前置词、后置词和完全无自动词；Preview 与真实 ComfyUI 提交共用同一提示词合成函数。
