# v2.7.9 图片模型引用参数精简

产品版本：v2.7.9  
发布日期：2026-11-08  
Table Action API：v0.1 / Phase 4.7  
Action Definition：1.4

## 本轮目标

在不改变现有 Provider、ComfyUI Workflow 与旧表格配置结构的前提下，精简“图片生成模型由字段引用”时的参数界面，并确保每一行只向实际解析出的模型提交其支持的参数。

## 主要更新

- 模型使用 `{字段名}` 动态引用时，统一展示分辨率、比例、生成数量、生成模式、画质、复杂度与输出格式。
- TT Image 2.6 使用复杂度与 PNG/SVG/GIF；TT Image 2.5、Qwen、Face 等模型自动忽略不支持的专属参数。
- 输出格式通过字段引用解析为 GIF 时，固定采用 9 帧、200ms 单帧时长，不再读取过去保存的 GIF 二级参数。
- 动态 Qwen 路由隐藏 LoRA 设置，并默认仅应用已登记的 `consistency` 高保真 LoRA；Qwen Face 和其他模型不会误加载残留 LoRA。
- 格式字段除 `png/svg/gif` 外，新增 `.png/.svg/.gif` 写法兼容；继续支持 `jpg/jpeg/webp` 及既有中文别名。
- 固定 TT Image 2.5、Qwen 等模型不再因为配置里残留 TT Image 2.6 参数而错误显示复杂度和格式区。
- `generation.preview` 与真实生成共用相同的动态参数和 LoRA 解析规则。

## 兼容性说明

- 不迁移、不删除旧表格中的图片生成配置；切回固定 TT Image 2.6 时原固定参数仍可继续使用。
- 不新增 Action，不修改 Action 参数 Schema；`field.configure_ai` 现有字段保持兼容。
- `tt-image-2.6-guan` 仍不支持 SVG，解析到该组合时明确报错，不静默改成 PNG。
- Table Action API 协议版本、Phase 与 Action Definition 版本均保持不变。
