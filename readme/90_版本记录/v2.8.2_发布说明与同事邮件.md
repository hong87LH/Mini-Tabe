# AI Table Studio v2.8.2 发布说明与同事邮件

发布日期：2026-11-24
发布主题：智能裁切双模型轮廓、近似比例与 Agent 临时参数

## Git Release 文案

AI Table Studio v2.8.2 将智能裁切正式升级为 PoseLandmarker 姿态识别与独立 ImageSegmenter 人物语义轮廓的双模型方案。头像裁切会读取真实发顶与头发左右边缘，受限画幅下优先缩减肩部语境，不再以裁断头发换取更多身体；上衣、短裙等服装裁切使用骨骼确定纵向范围、语义 clothes 轮廓确定横向宽度。

本版新增固定比例与近似比例两种求解方式。短裤/半裙预设可在 1:1、3:4、4:3、9:16、16:9 中逐图选择能完整保护目标轮廓的比例。Agent Action 支持在共享预设上添加仅本次生效的 overrides，可临时调整头像留白、肩部深度、身体范围、留白与候选比例，不污染右键菜单配置。

姿态和轮廓结果分别缓存到 IndexedDB；模型与 MediaPipe WASM 通过 HTTPS 加载并使用 Electron/Chromium HTTP Cache。轮廓下载或识别失败时会自动退回关键点方案，不阻塞整批任务。右键菜单、Agent 与人工预览继续复用原 cropData，旧工程无需迁移。

正式发布边界不包含试验性的手部剔除和 lower_garment 下装专用模式。回退后 TypeScript 类型检查、UI 工作流 63/63、生成预览策略 12/12 与生产构建均通过；Action Definition 为 1.7，协议仍为 v0.1 / phase4.7。
