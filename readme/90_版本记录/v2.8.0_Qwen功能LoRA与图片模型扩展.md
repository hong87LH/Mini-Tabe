# AI Table Studio v2.8.0 升级说明

发布日期：2026-11-16
兼容基线：v2.7.9 及既有 2.7.x 表格、字段和生成任务
Action API：v0.1 / Phase 4.7
Action Definition：1.4

## 本次更新

### 1. Qwen 人物功能 LoRA 正式接入

- 默认 Qwen Image 2.1 工作流登记 `xiaoxue-a` 与 `mumu-v02` 两个 Profile。
- Profile 可携带完整默认提示词，并在其后追加表格普通文本、智能文本或分析结果。
- LoRA 字段引用使用稳定 Profile ID；设置页展示名、模型文件名与字段值保持明确区分。
- 人物 LoRA 以完整角色提示词为基底，不加入不稳定的发型剔除路由。
- `loraProfiles` 为可选配置，旧表格未配置时继续按原工作流运行。

注册与后续维护统一参见：[Qwen Image 2.1 参数与 LoRA](../03_ComfyUI/ComfyUI_Qwen_Image_2.1_参数与LoRA.md)。

### 2. 图片模型路由扩展

- 新增即梦 5.5：`doubao-seedream-5-5-261028`，支持最多 10 张参考图、1K/1.5K/2K 与常用比例。
- 新增 MiniMax H3 图像：`minimax-h3-image`，支持最多 16 张参考图、standard/highspeed、1K/2K/4K 与扩展画幅。
- 两个新模型均按现有灵晤异步任务协议接入，并统一固定输出 PNG。
- 参数界面按模型能力显示与透传；无关参数不提交，不影响 TT Image 2.6 的 SVG/GIF 专用设置。

### 3. Action 与维护能力

- `generation.get_capabilities` 同步公开新图片模型能力和 Qwen LoRA Profile。
- `generation.preview` 可校验 LoRA Profile ID，并回显实际选择。
- 工作流、模型来源、LoRA 文件与中央模型库硬链接记录已同步维护。
- Qwen LoRA 视觉分析 Skill 独立通过 Git 安装，不捆绑进主工程。

## 兼容性

- 保持现有模型别名、字段结构与 Action API v0.1 不变。
- v2.7.9 及更早 2.7.x 表格可直接打开；缺少新增字段时采用原默认逻辑。
- 即梦 5.5 与 MiniMax H3 不新增普通位图格式设置，避免改变现有统一参数引用规则。
