# AI Table Studio v2.8.2 升级说明

发布日期：2026-11-23
主题：智能裁切双模型轮廓版

## 本版变化

- 姿态识别继续使用 `PoseLandmarker Full`，关闭其内置分割回调；
- 新增独立 `ImageSegmenter` Worker，以 category mask 输出人物、头发、脸、皮肤与服装轮廓；
- 轮廓连通域按姿态关键点匹配到具体人物 ID，支持多人画面；
- 轮廓结果保留完整人物、头脸及头发/面部/皮肤/服装/配饰的分层行区间，紧凑头像不再把肩部、衣服或手臂算进头部包围盒；
- 紧凑头像以真实头发像素和最低顶部安全线作为硬约束，以理想留白和肩部深度作为软构图目标；
- 轮廓失败时自动退回面部、颈部与肩部关键点估算，不阻塞批量任务；
- 姿态和轮廓分别写入 IndexedDB，同图切换预设无需重复推理；
- Agent Action 支持在共享预设之上追加仅本次有效的安全 `overrides`，可临时调整画幅、头像留白或通用人体范围，不污染右键菜单配置；
- 通用人体预设新增固定比例与近似比例两种模式；近似模式会在 `1:1 / 3:4 / 4:3 / 9:16 / 16:9` 中逐图选择能完整保护目标轮廓的比例；
- 服装裁切改为骨骼关键点确定纵向区间、语义 `clothes` 轮廓确定横向宽度，宽摆短裙和蓬松上衣不再被骨架宽度截断；
- `shorts_skirt_3_4` 保持原 ID 兼容自动化任务，但默认启用近似比例；
- 模型和 WASM 继续使用 Electron/Chromium 普通 HTTP Cache；
- Electron 运行时与依赖锁定为 `41.3.0`。
- Action Definition 更新为 `1.7`，协议仍为 `v0.1 / phase4.7`。

## 头像裁切优化说明

旧方案的发顶主要由眼、耳、鼻、颈部等关键点外推，遇到蓬松发型、长发、头部倾斜时容易留白不稳定。v2.8.2 会先确定主人物，再以语义分割中的头发与面部分类建立头部包围盒：发梢最高点即使很细也属于不可裁断边界，衣服、手臂和肩部只参与下方构图，不参与头部尺度计算。

紧凑头像预设新增理想顶部留白 `topMargin=0.14` 与最低安全线 `minTopMargin=0.06`。原图空间充足时采用理想留白；1:1 画幅受限时可以小幅下移补足肩部，但绝不跨过头发与最低安全线。这套“语义硬保护 + 姿态锚点 + 软语境”结构同样可复用于上衣、裤装和配饰裁切。

分割轮廓是辅助约束，不是唯一依据：模型下载失败、分割超时或轮廓无法与姿态人物匹配时，仍会使用原关键点保底方案。
