# v2.7.4 局域网 ComfyUI、模型映射与审阅优化

发布日期：2026-10-09。Git 发布基线为 v2.7.2；用户所称 v2.7.3 为上一轮局域网功能阶段，本次合并发布至 v2.7.4。

## 相对 Git v2.7.2

- 本地应用设置新增 ComfyUI 服务地址，支持局域网 HTTP/HTTPS 服务。默认或留空为 http://127.0.0.1:8188，应用到当前 ComfyUI 图片和视频提供商；远程连接失败不启动本机 BAT，模型选择不依赖 BAT 路径。
- 新增 banana-2.1 的灵晤映射，保留实际模型名；模式 auto/high 对应 thinkingLevel minimal/high，无独立画质参数。支持1K/2K/4K、14种比例及最多14张参考图配置，沿用 Flash 3.1 参考图处理。未自动开启联网搜索。
- 审阅视图先筛选列再去重，修复同图先出现在未选列时造成的漏图，保持所选列记录关联。
- 审阅大图默认显示完整图片，手动点击裁切按钮恢复已保存裁切；退出恢复整图。表单预览仍自动展示已有裁切，裁切数据不删除、不影响生成。

## 相对 v2.7.3 局域网功能阶段

本次新增 banana-2.1 参数映射、审阅列筛选漏图修复，以及审阅预览手动进入裁切。局域网功能继续保留。
