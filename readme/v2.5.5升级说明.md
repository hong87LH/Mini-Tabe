# Lingwu v2.5.5 升级说明

## 版本目标

本版本将 MiniMax H3 本地多参 Fast、ComfyUI 长队列、音频缩略图和标签字段清理逻辑正式收口。

## 1. 多参 Fast 与 Turbo LoRA

- `minimax-h3-Ref-local` 的 Fast 模式使用 6 步模板和 `MiniMaxH3TurboLoRA`。
- 图片或视频与独立音频混合输入时，自动插入 `H3TurboMixedReferenceFix`。
- 修正节点来自 `Hongs-node`，不会修改第三方 Turbo 插件。
- Quality 模式保持原速 20 步，不插入 Turbo 修正节点。

## 2. 本地任务 Timeout 修正

旧逻辑从任务提交开始累计约 30 分钟，其中包含 ComfyUI 队列等待时间。长 Ref 任务排在前面时，后续任务虽然仍在 ComfyUI 队列中，前台却可能先被标记为 Timeout。

v2.5.5 对本地 ComfyUI 使用持久队列状态：只要任务仍处于 queued 或 running 就持续轮询，不使用远程供应商的 30 分钟总时限。单次状态请求仍有网络超时，避免接口连接永久挂死。手动“继续轮询”会清除旧错误并重置轮询状态。

## 3. 音频缩略图

- 保留缩略图中央的大音符，用于区分图片、视频和音频。
- 不再添加底部的小音符角标。
- 有内嵌封面的音频继续显示封面；无封面时显示渐变底图。

## 4. 标签字段往返清理

最轻量方案是把“标签转文本”作为清理边界：

1. 标签转文本时，只保留当前字段选项表中仍然存在的标签 ID；已删除或无效 ID 自动变为空，不再把无效 ID 当作标签文字保留下来。
2. 文本转回单选或多选时，只根据当前单元格文本重建选项。
3. 支持英文/中文逗号、英文/中文分号和换行分隔，并自动去重、忽略空值。
4. 同名有效选项复用原 ID 和颜色，没有被任何当前文本引用的旧选项自动清除。

因此用户只需执行一次“标签 → 文本 → 标签”，即可轻量清理整列无效标签。

## 可选 ComfyUI 自动启动

- API 设置 → 本地应用设置新增“ComfyUI 启动 BAT 路径”。
- 该项不必填写；留空时维持原行为。
- 调用本地 ComfyUI 前先检查端口。服务正常时不会运行 BAT。
- 本地端口失败且配置了 BAT 时，以可见黑色命令窗口运行 BAT，最长等待 120 秒恢复服务，然后继续提交任务。
- 任务轮询过程中若本地 ComfyUI 意外退出，也会尝试按相同路径恢复。
- 为避免误启动远程程序，自动启动只允许 `127.0.0.1`、`localhost` 或本机 IPv6 回环地址。
