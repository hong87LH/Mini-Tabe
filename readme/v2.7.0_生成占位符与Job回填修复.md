# AI Table Studio v2.7.0：生成占位符与 Job 回填修复

日期：2026-09-07

产品版本：2.7.0；Table Action API：v0.1 / phase4.7（协议及能力阶段不变）。

## 修复内容

- 修复生成中的 Job 占位符被当作普通图片加载，空路径缓存命中后反复重试造成展开单元格卡住的问题。图片组件对空路径直接停止加载。
- 中缩略图为 Job 占位符显示“生成任务待回填”，不进入图片加载或大图预览。删除按钮沿用普通附件的悬停显隐效果；移除占位符不取消后台任务。
- 预览列表只接收有效媒体，编辑媒体时保留尚未回填的占位符。
- 重启、表格数据加载及变更后重新核对已完成 Job；同一单元格多个任务合并回填，不再互相覆盖。行列 ID 不通过连字符拆分，兼容包含连字符的 ID。
- 同一 Job 出现在多个单元格时逐格处理；同路径结果去重并保留原附件的评分、裁切等属性。支持附件、AI 图片和 AI 视频列。
- 保留进行中、未知以及完成但尚无结果路径的占位符；失败或取消的任务仅移除对应标记。
- 同步应用及 Action API 产品版本元数据至 2.7.0，修正此前 API 仍显示 2.6.8 的版本信息。

## 验证

- Job 回填新增 6 项回归测试，与原界面工作流测试合计 33 项通过。
- 独立 Electron 组件测试：旧代码空路径缓存对照出现渲染器超时；修复后空路径请求数为 0，定时器响应、状态显示、移除占位符通过。
- 使用长期工程实际 CSS 验证普通附件同款悬停规则：隐藏透明度 0，模拟 Chromium 悬停状态透明度 1；隐藏窗口测试关闭过渡以避免后台动画冻结影响断言。
- 长期工程生产构建通过；用户已实际运行确认修复可用。
- 类型检查仍存在原有 TS2347 问题，本轮未扩展修改范围。

## 结构与升级

业务修改集中在 Grid.tsx；新增 networkJobReconciliation.ts 提供可测试的回填逻辑，及一份对应回归测试。没有新增 Service/Manager 层或运行依赖。

保存当前表格后重启应用。历史附件无需迁移，已有占位符由 Job 记录核对恢复。未知任务不会自动删除。

发布只同步源码、测试、版本元数据与文档；不包含 node_modules、FFmpeg 程序、dist、用户表格数据或维护目录的临时测试文件。Git 根 README 仅追加一行版本摘要。
