## 需要重点替换的旧说法

旧说法：**“Qwen 图生图始终跟随第一张参考图比例，比例字段不起作用。”**

新说法：

- **自动/未填写比例：**图生图跟随第一张参考图。
- **明确填写具体比例：**图生图使用 `EmptyLatentImage` 覆盖采样画布。

## 使用建议

- 想保留首图构图：比例选 **自动（图生图跟随首图）**。
- 想强制改成海报比例：直接选 `3:4`、`9:16`、`1:1` 等具体比例。
- 升级后请**完整重启 Electron 与 ComfyUI**，不要只热更新前端。


## 局部修图优先级回归修复（2026-09-26）

- 发现 v2.7.2b 的 Qwen 请求组装仍按下拉框原始值判断“是否显式传入比例”，忽略旧版局部修图从第一张图片 `cropData.ratio` 得到的有效比例。
- 调整为：局部修图第一张原始图片的裁切比例优先；无裁切元数据时读取第一张实际原图宽高；两者均优先于手工比例和引用字段。
- 对 Qwen，局部修图比例显式传入 ComfyUIClient，使用 workflow 节点 90 `EmptyLatentImage` 采样；辅助参考图不能抢占局部修图源图的 `image_1`。
- 未启用局部修图时，Qwen 的“自动跟随首图 / 指定比例控制画布”维持不变；其他 Provider 已有裁切比例覆盖规则不变。
